# ViaTrail

**ViaTrail** — Android-приложение для планирования автомобильных путешествий и поиска интересных мест по пути. Оно помогает построить маршрут между городами, подобрать остановки и сохранить план поездки.

## Возможности

- **Построение маршрутов** между выбранными городами с отображением на интерактивной карте.
- **Поиск мест по пути:** достопримечательности, кафе и отели.
- **Планирование остановок:** выбор подходящих мест и изменение их порядка в маршруте.
- **Сохраненные путешествия:** хранение составленных маршрутов на устройстве.
- **Переход к навигации:** открытие выбранной точки во внешнем навигаторе.

## Технологии

Приложение разработано на **Kotlin** с использованием **Jetpack Compose**, **MVVM** и **Clean Architecture**. Для внедрения зависимостей используется **Hilt**, для локального хранения — **Room**, для отображения карт — **MapLibre**. Картографические данные, маршруты и поиск мест предоставляются через **Geoapify** на основе данных **OpenStreetMap**.
