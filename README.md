# ViaTrail

ViaTrail — Android-приложение для планирования автомобильных путешествий и поиска интересных мест по пути. Позволяет строить маршруты между городами, выбирать и автоматически подбирать остановки, сохранять поездки и продолжать путешествие с учетом посещенных точек.

## Возможности
- Построение маршрутов и поиск остановок с учетом максимального крюка и времени поездки.
- Автоматический подбор мест и ручное изменение порядка остановок.
- Карточки достопримечательностей, кафе и отелей, проверенные свободные фотографии из Wikimedia Commons при наличии.
- Сохранение поездок, просмотр маршрутов и истории без повторных сетевых запросов.
- Загрузка небольшого участка карты для просмотра без сети (без офлайн-перестроения маршрута).
- Режим поездки с геопозицией, отметками посещенных мест и переходом во внешний навигатор.

## Технологии
Kotlin, Jetpack Compose, Material 3, Clean Architecture, MVVM, Hilt, Room, MapLibre, Geoapify, OpenStreetMap, Wikimedia Commons.
