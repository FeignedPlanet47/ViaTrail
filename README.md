# ViaTrail — Android starter MVP

Новый самостоятельный Android-проект: **Kotlin + Jetpack Compose + MVVM + Clean Architecture (app/data/domain) + Hilt + Room + MapLibre**.

Возможности: поиск маршрута между городами, поиск интересных мест/кафе/отелей вдоль маршрута через Geoapify, ручной выбор и порядок остановок, сохранение поездок в Room, просмотр маршрута и переход во внешний навигатор.

## Запуск

1. Открой папку `ViaTrail-Android` в Android Studio с JDK 17 и Android SDK 36.
2. Создай проект и ключ на https://myprojects.geoapify.com/ . Учитывай квоты и ограничения ключа. **Не добавляй ключ в GitHub**.
3. Добавь в `~/.gradle/gradle.properties` (глобальный файл, вне репозитория):

    GEOAPIFY_KEY=твой_ключ

4. Выполни Sync Project with Gradle Files, затем Run на Android 8+.
5. Если Gradle wrapper JAR отсутствует, Android Studio может запустить установленный Gradle; лучше установи Gradle wrapper в проекте с помощью `gradle wrapper --gradle-version 8.11.1`.

## Правообладатели и публикация

- Карта, поиск, маршруты и POI: Geoapify, лицензия/условия https://www.geoapify.com/pricing/ ; карта содержит лицензированные данные OSM по ODbL; сохраняй атрибуцию **© OpenStreetMap contributors · Powered by Geoapify**.
- Рендеринг: MapLibre Native, открытый исходный код, проверяй LICENSE зависимости при выпуске.
- В проект не встроены чужие фотографии, брендовые логотипы, недозволенные тайлы, скопированные тексты или публичные бесплатные демонстрационные endpoints.
- API-ключ внедряется в сборку приложения и **может быть извлечен из APK**. Для production обязательно настрой ограничения ключа, лимиты/мониторинг в Geoapify или перенеси вызовы через собственный backend с безопасной аутентификацией. Отсутствие ключа в git само по себе не защищает его в APK.
- Запросы к геокодеру и POI выполняются по действию пользователя, а не на каждый вводимый символ. Нет фонового массового скачивания тайлов.
- Для Google Play targetSdk 36. Перед выпуском: актуализировать зависимости, проверить API/права, тесты, Data Safety/политику конфиденциальности, условия хранения/кэширования и расчеты провайдера.
- Нет геолокации, рекламы, аналитики, регистрации и фото: это снижает объем персональных данных. Введенные города и точки поездки отправляются в Geoapify — опиши это в privacy policy.

## Ограничения прототипа

- Не проверен Gradle build в текущем окружении без Android SDK. Исправления могут потребоваться при синхронизации.
- Поиск POI использует три контрольные точки линии маршрута и радиус 5 км; это MVP, а не точный поиск по геометрическому коридору.
- Внешний навигатор открывает выбранную остановку, не обеспечивает turn-by-turn навигацию внутри приложения.
- Карты и API требуют интернета и действующего аккаунта Geoapify.
- Приложение пока не готово к немедленной публикации без тестирования на устройствах, реализации privacy policy и проверки условий провайдера на дату релиза.
