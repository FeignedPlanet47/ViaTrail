# ViaTrail — разработка и ограничения MVP

## Что реализовано

1. **Планирование**: выбор городов, категории мест, допустимого дополнительного километража, времени остановки и суммарного времени. Сначала строится прямой маршрут, точки предварительно фильтруются по расстоянию до геометрии маршрута. При добавлении точки Geoapify считает полноценный дорожный маршрут, и ограничения проверяются по нему.
2. **Карточки**: название, адрес, описание (если доступно), координаты, примерная близость к маршруту, время посещения, ссылка на сайт при наличии. Добавить, убрать, пропустить. Изображения намеренно не подтягиваются автоматически без верифицированной лицензии.
3. **Мои путешествия**: Room, сохранение маршрута, его геометрии и остановок, восстановление без сетевого запроса, редактирование после онлайн-обновления, перестановка точек и удаление. Миграция Room версии 1 → 2 сохраняет прежние поездки.
4. **Режим поездки**: разрешение на геолокацию только по действию пользователя, запрос текущей позиции, прямая дистанция до следующей точки, отметка «посещено», открытие внешнего навигатора. Фоновое отслеживание отсутствует.
5. **Офлайн-копии**: сохраненные маршруты/точки/геометрия доступны без интернета. Отображение фоновой карты зависит от доступа к лицензированным тайлам. **Офлайн-карты и офлайн-перестроение маршрута не реализованы** — для них нужен провайдер с явным правом офлайн-загрузки либо собственная инфраструктура.

## Настройка

- Android Studio, Android SDK 36, JDK 17.
- В `~/.gradle/gradle.properties` добавить `GEOAPIFY_KEY=...`. Файл не загружать на GitHub.
- Открыть папку проекта, выполнить Gradle Sync и `:app:assembleDebug`. В архиве не включен gradle-wrapper.jar: сгенерируйте wrapper установленным Gradle, либо настройте Android Studio на локальную установку Gradle.
- Важно: ключ в Android BuildConfig можно извлечь из APK. Ограничьте ключ по возможностям провайдера, следите за расходом и при росте нагрузки используйте backend-прокси.

## Сервисы и авторские права

- MapLibre (открытая библиотека) используется для отображения; карта и API — Geoapify по его условиям и тарифу.
- На главном экране отображаются «© OpenStreetMap contributors · Powered by Geoapify». Сохраняйте атрибуцию и проверьте точные требования поставщика перед публикацией.
- Никакой массовой загрузки публичных OSM-плиток. Geoapify не является источником готовых офлайн-плиток для свободной перепаковки без согласования.
- Публичный API и правила использования могут меняться; проверьте условия, квоты и допустимость кеширования перед релизом.
- Для фото требуется отдельно проверить лицензию каждого файла и реализовать подписи (автор, источник, лицензия, ссылка); поэтому в этой версии изображения не добавлены.
- Для Google Play и RuStore подготовьте политику конфиденциальности, Data safety, необходимые декларации геолокации и проверку на реальных устройствах.

## Известные ограничения

- Близость найденных мест к линии маршрута — геометрическая оценка; реальный крюк проверяется только при добавлении конкретного места.
- Поиск мест выполняет до 7 запросов на маршрут; расход квоты зависит от длительности поездки. При масштабировании нужен поиск вдоль маршрута с оптимизацией запросов/кэширования.
- Продолжительность посещения задается пользователем, а не прогнозируется сервисом.
- После открытия офлайн-копии для редактирования нужно нажать «Обновить маршрут онлайн».
- Текущая геопозиция не обновляется автоматически, пользователь запрашивает ее вручную. Нет turn-by-turn навигации.
- Фотографии, полноценный офлайн-картографический слой и офлайн-перестроение остаются задачами следующих этапов.
