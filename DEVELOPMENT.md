# ViaTrail 0.3 — этапы разработки

1. **Compose UI:** новая трехвкладочная структура, Material 3, светлая/темная темы, карточки маршрутов и BottomSheet объектов.
2. **Автоматический подбор:** `domain/AutoPlanner.kt`. Проверяются реальные дорожные крюки и время через Geoapify Routing. Жадная эвристика, не глобально оптимальное решение. Ограничение 12 кандидатов на итерацию и 5 остановок — избегать чрезмерных API-запросов.
3. **Фотографии:** `CommonsPhotos.kt` использует Wikimedia Commons API, показывает только фото с проверенными метаданными Public domain / CC0, ссылкой на оригинал, лицензией и автором. Фотография ищется по названию и может не соответствовать месту — проверяйте визуально. При отсутствии подходящей лицензии фото не отображается.
4. **Режим поездки:** обновление координат раз в 15 секунд только пока открыт экран, предложение отметить остановку при расстоянии < 200 м, прогресс посещений сохраняется в Room. Расстояние указано по прямой, не ETA по дорогам.
5. **Офлайн:** сохраненная геометрия, точки и прогресс работают без интернета. Добавлена загрузка маленького участка карты вокруг начала маршрута (~10 км) через MapLibre OfflineManager, зум 10–14, с прогрессом. Не реализованы скачивание целых регионов, управление/удаление участков и офлайн-перестроение маршрута. Для выпуска проверить фактическую полноту стиля/шрифтов и условия Geoapify.
6. **Публикация:** перед выпуском нужны настоящая сборка Android Studio, UI/интеграционные тесты, своя политика конфиденциальности, Data safety, атрибуции, ответственность за API ключ, ограничение квот, иконки и AAB. Не коммитьте API-ключ.

## Известные ограничения
- Поиск Wikimedia Commons по имени не гарантирует соответствие снимка объекту.
- Автоподбор ограничен по числу запросов, не гарантирует мировой оптимум и учитывает только существующие открытые API.
- Офлайн-перестроение и загрузка целых регионов не реализованы; есть экспериментальная загрузка небольшого участка.
- Полной компиляции Android Gradle в среде генерации не было. Проверяйте сборку перед публикацией.
